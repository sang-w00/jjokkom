다운로드 파일 SHA-256 확인하기

앱 업데이트는 HTTPS와 배포된 SHA-256으로 파일을 검증합니다. 이는 코드 서명·공증을 대체하지 않으며, 배포 계정과 사이트를 신뢰해야 합니다.

공식 업데이트 정보가 준비되면 여기에 실제 파일 해시가 표시됩니다.

Mac: shasum -a 256 파일.zip
Windows PowerShell: Get-FileHash 파일.exe -Algorithm SHA256

HELLO, JJOKKOM

처음 만나는 쪼꼼,
이렇게 시작해요.

화면은 ‘데모 시작하기’로 먼저 둘러볼 수 있어요.
실제 편지를 주고받으려면 두 사람만의 서버 연결이 필요해요.

1

각자 설치하고 내 모습 고르기

이름과 상대방에게 보여 줄 캐릭터를 골라요. 내 바탕화면에는 상대방의 친구가 나타나요. 설정에서 내 친구도 함께 보이게 할 수 있어요.

2

한 사람이 서버 준비하기

Supabase 전용 프로젝트를 만들고 익명 로그인을 켜 주세요. 앱 도움말의 최신 서버 설정 SQL을 실행하고 비공개 Realtime 설정을 확인해요.

3

초대장을 비공개로 전달하기

‘연결하기’에 Project URL과 공개 키를 저장한 뒤 초대장을 만들어요. 상대방은 초대장 전체를 붙여 넣고 연결해요. 짧은 편지를 서로 보내 확인해 보세요.

서버에는 어떤 키를 입력하나요?

Supabase의 Project URL과 publishable key 또는 legacy anon key만 앱에 입력해요. service_role, sb_secret_…, 데이터베이스 비밀번호는 절대 넣지 마세요. RLS를 끄거나 SQL 오류를 무시해 연결하지 마세요. 최신 SQL과 상세 단계는 앱의 도움말에서 확인할 수 있어요.

Supabase 대시보드 →

같은 계정으로 여러 노트북을 쓰고 싶어요.

원래 연결된 기기에서 이메일과 12자 이상 비밀번호로 계정 등록을 시작해요. 확인 메일로 주소를 확인한 뒤 원래 기기에서 같은 이메일·비밀번호로 등록 버튼을 한 번 더 눌러 비밀번호 설정을 완료해 주세요. 다른 기기에는 같은 서버 URL과 공개 키를 저장하고 같은 계정으로 로그인해요.

서버의 Manual Linking을 켜야 해요. 프로젝트 팀 밖의 이메일에 확인 메일을 보내려면 Custom SMTP 설정이 필요해요. 이메일 인증을 끄지 마세요. Supabase 발송 설정과 제한 →

기기별 독립 세션을 사용하며 비밀번호로 암호화된 대화 키를 기기에서 복원해요. 원래 기기를 종료하거나 세션을 복사할 필요는 없어요. 비밀번호·초대장·암호화 키를 공개 게시하지 마세요.

초대장과 편지는 어떻게 보호되나요?

편지는 기기에서 암호화한 뒤 서버로 보내요. 초대장은 대화 키를 포함하므로 상대방에게만 비공개로 전달해 주세요. 연결에는 두 사람만 가입할 수 있지만 같은 계정의 독립 로그인 기기는 여러 대 사용할 수 있어요. 비밀번호와 기기의 대화 키를 모두 잃으면 기존 편지를 복호화하지 못할 수 있어요.

INSTALL & UPDATE

안전하게 설치하고,
오래 함께 쓰기.

Mac에서 처음 설치할 때

  1. 내 칩에 맞는 ZIP을 풀고 Jjokkom.app을 응용 프로그램 폴더로 옮겨요.
  2. 출처를 확인한 뒤 앱을 열어요. 차단되면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 확인해요. macOS 버전에 따라 앱을 우클릭해 ‘열기’도 사용할 수 있어요.
  3. ‘손상되었음’ 등 다른 경고라면 실행을 강제하지 말고 파일 출처와 다운로드를 다시 확인해요. Gatekeeper 전체 해제 명령은 사용하지 않아요.

Windows에서 처음 설치할 때

  1. 공식 GitHub의 EXE 설치 프로그램을 실행해요.
  2. SmartScreen이 표시되면 출처를 확인하고, 신뢰하는 파일에 한해 추가 정보 → 실행을 선택해요. 조직 정책으로 차단됐다면 관리자에게 문의해요.
  3. 현재 사용자용으로 설치돼요. 바탕화면이나 시작 메뉴에서 쪼꼼을 실행해 주세요.

이미 쓰고 있다면

앱의 업데이트 확인 → 업데이트 설치를 눌러 주세요. 파일 검증 후 Mac은 앱을 종료하고 교체·재실행하며, Windows는 설치 프로그램을 실행해요. 인터넷 연결이 필요합니다.

이 업데이트 기능은 0.4.0부터 제공돼요. 0.3.x 앱에서는 먼저 이 페이지의 새 설치 파일로 앱을 교체해 주세요. 기존 앱 데이터 폴더는 지우지 마세요. 두 사람 모두 같은 최신 버전을 사용하고, 기존 서버에는 앱 도움말의 0.4.0 마이그레이션 안내를 적용해 주세요.

Mac에서 새 앱 시작에 실패하면 이전 앱을 복원해요. 권한·보안 설정 때문에 자동 업데이트가 안 되면 확인된 파일로 수동 교체할 수 있어요.
